# Qward character sprites

The body remains sprite-based:

- `qward-body.png` - fixed body outline/base
- `qward-body-color.png` - recolorable body layer

The `#ff0000` region in the color layer is replaced by the selected BODY color.

Arms and legs remain procedural. They are rendered with one connected pixel-style outline underneath the complete bent limb.

Hands and feet are generated pixel circles with matching outlines. Foot sprites are no longer used.

The older `qward-hand.png` and `qward-hand-color.png` files are currently unused and may be repurposed later.
